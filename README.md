# Chapter & Cup — Book Café

Chapter & Cup is a responsive, interactive book café website designed to showcase a cozy neighbourhood café where visitors can explore reading spaces, browse a menu, and make a table reservation. Developed using HTML, CSS, and JavaScript, the project demonstrates interactive web features, responsive styling, and client-side form validation as part of a Web Development assignment.

## ✨ Features

- **Café Introduction:** Explore the café's story, atmosphere, and reading spaces.
- **Interactive Menu:** Filter menu items by drinks and pastries.
- **Order Total:** Select menu items and calculate the total price.
- **Theme Switcher:** Toggle between light and dark themes.
- **Table Reservation Form:** Enter reservation details with client-side validation.
- **Age-Based Discounts:** Display student and senior discount eligibility based on birth year.
- **Read More / Read Less:** Expand or collapse the café's story.
- **Opening Status:** Display the café's opening status based on the current time.
- **Character Counter:** Track the remaining characters in special requests.
- **Gallery:** View images showcasing the café's atmosphere.
- **Responsive Design:** Adapt the website layout to different screen sizes.

## 🛠️ Technologies Used

- HTML5 — Structure and content
- CSS3 — Styling, responsive layout, and themes
- JavaScript — Interactivity, event handling, and form validation

## 🚀 How to Run the Project

You can view the live project directly here:

[Live Demo]https://fatimaatech.github.io/WebDev-Assignment/

Alternatively, to run it locally:

1. Clone or download this repository.
2. Open the project folder.
3. Double-click the `index.html` file.
4. The website will open automatically in your default web browser.

For the best experience, use a modern browser such as Google Chrome or Mozilla Firefox.
